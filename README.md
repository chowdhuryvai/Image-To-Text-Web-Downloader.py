## ✨ Features

### 📥 Website Image Downloader
- ✅ Download all images from any website
- ✅ 4 Quality Options (Original/HD/Medium/Low)
- ✅ Multi-threaded fast downloading
- ✅ Auto domain-based folder organization
- ✅ Real-time progress tracking
- ✅ Resume support for failed downloads
- ✅ Smart image detection from HTML/CSS

### 📝 Image to Text (OCR)
- ✅ Extract text from images
- ✅ **Bangla (বাংলা)** language support
- ✅ **English** language support
- ✅ **Mixed (Bangla + English)** support
- ✅ Auto image preprocessing
- ✅ Multiple OCR attempts for best results
- ✅ High accuracy text extraction

### 🎨 Modern GUI Interface
- ✅ Dark theme professional design
- ✅ Drag & Drop support
- ✅ Real-time status updates
- ✅ Keyboard shortcuts
- ✅ Copy to clipboard
- ✅ Save as TXT/PDF/DOCX
- ✅ Built-in file explorer

### 🔧 Auto-Install System
- ✅ One-click Tesseract installation
- ✅ Auto-detection of missing components
- ✅ Cross-platform compatibility
- ✅ No external Python modules needed
- ✅ Works with Python built-in libraries only
